# AI 規則延伸示範與測試

## 示範：依照規則新增 RSI 教學文章
開發指令：
> 請閱讀根目錄 AGENTS.md，依照既有文章 schema 在 data/articles.json 新增「RSI 相對強弱指標」教學文章，維持原本配色、分類、搜尋與文章詳頁功能，並確認可在 GitHub Pages 正常瀏覽。

## 本專案的實作結果
`data/articles.json` 已包含 id=`rsi` 的文章，含「常見解讀」、「趨勢市場」與「注意事項」三段內容。這筆資料不需要為它新增 HTML 頁面，就能由 JavaScript 自動渲染文章卡片與詳細頁。

## 驗證方式
1. 啟動本機伺服器並開啟首頁，點「知識文章」。
2. 在搜尋框輸入 `RSI`，應僅顯示 RSI 文章。
3. 點入卡片，網址應顯示 `#article/rsi`，並顯示三段教學。
4. 按「返回文章列表」可返回搜尋與分類頁。
5. 移至手機寬度，確認卡片自動改為單欄。
6. 以後新增另一篇文章時，只需修改 `data/articles.json`，維持同一結構即可。
